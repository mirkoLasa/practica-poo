# Práctica de Python: POO y CRUD

En este proyecto estoy aplicando los conceptos fundamentales de Programación Orientada a Objetos en Python.

## Estructura del proyecto
- `multimedia.py`: Versión inicial con las clases base y herencia.
- `CRUD_multimedia.py`: Versión avanzada que implementa un sistema CRUD (Create, Read, Update, Delete) interactivo a través de un menú en consola.

## Tecnologías utilizadas
- Python 3
- Git/GitHub para control de versiones

## Aprendizajes clave
- Clases, herencia (`super()`) y polimorfismo.
- Implementación de lógica CRUD.
- Uso de `isinstance` para validación de objetos.
